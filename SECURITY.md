# Security

Any AAC is someone's voice, so a security problem can also be a safety problem. It has no server, accounts or analytics: boards, settings and voices stay in the browser on the device, and the hosted app only contacts its own site.

## Reporting a problem

Please report it privately, through [GitHub's private vulnerability reporting](https://github.com/tks98/any-aac/security/advisories/new) (the **Security** tab → **Report a vulnerability**), not in a public issue. Say what you found, how to reproduce it and what it lets someone do. We'll reply as soon as we can, work on a fix with you, and credit you when it's published unless you'd rather not be named.

Examples of what we'd like to hear about:

- A board file, backup or picture that runs code, or changes something it shouldn't, when it's imported or opened.
- Anything that makes the app send data to another site, or load code from one.
- A way to get past the edit lock, or to change someone's boards or settings without them knowing.
- Anything that stops the app speaking, or loses someone's boards.

## Supported versions

Fixes go into `main`, which [any-aac.com](https://any-aac.com/) runs; people get them the next time the app updates. If you self-host, update to the latest [release](https://github.com/tks98/any-aac/releases).
