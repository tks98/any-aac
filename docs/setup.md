# Setting up a device

For families, teachers and speech-language pathologists (SLPs) setting up Open AAC for someone. The app is still in early development; see the [README](../README.md).

## 1. Install it

Installing keeps the app full screen, lets it work offline, and stops iOS from clearing its data after a week without use.

- **iPhone or iPad:** open the app in Safari, tap Share, then **Add to Home Screen**. Open it from the Home Screen from then on.
- **Android:** open it in Chrome, open the ⋮ menu, then **Install app** (or **Add to Home screen**).
- **Computer:** in Chrome or Edge, use the install button at the right of the address bar.

Edit mode reminds you if the app isn't installed.

## 2. Choose one main device

Each word has one place on the board, and people learn where words are by moving to them, much as speakers learn to say words. That only works if the places don't change. On phone-sized screens Open AAC shows a smaller board with fewer words in different places, which is a second set of places to learn.

- For someone **starting out**, use a tablet or larger screen with big buttons as the main device. Vocabulary designers recommend this ([PRC-Saltillo](https://prc-saltillo.com/blog/LAMPWFL-iPhone)).
- If they use a **phone and a tablet**, consider turning off **Settings → Display → Smaller layouts on phones**, so both show the same board. The buttons will be small on the phone.

## 3. Choose a voice

**Settings → Speech & voice.** The device's own voice works straight away. An **Open AAC voice** sounds the same on every device and works offline; it's a one-time download of about 80 MB. **Linda** is recommended for English. Voices marked "licence isn't clearly open" may be withdrawn, so don't choose one as someone's long-term voice yet. There isn't a clearly licensed, good-quality Spanish voice yet ([research-check.md](research-check.md)).

Firefox on Android can't speak with device voices; use Chrome, or download an Open AAC voice.

## 4. Lock the device

Open AAC's own lock keeps editing behind a press-and-hold on **Edit**. To keep someone in the app, use the device's lock as well:

- **iPhone or iPad: Guided Access.** Settings → Accessibility → **Guided Access** → turn it on and set a passcode. Open Open AAC, triple-click the side button (or the Home button), and tap **Start**. Triple-click again and enter the passcode to end it.
- **Android: App pinning.** Settings → Security (on some phones, Security & privacy → More security settings) → **App pinning** → turn it on. Open Open AAC, open the recent-apps view, tap the app's icon and choose **Pin**. How to unpin varies by phone; it's usually holding Back and Overview, or swiping up and holding.
- **Windows: Kiosk.** Settings → Accounts → Other users → **Set up a kiosk**, choose Microsoft Edge, and give it the app's address.
- **Chromebooks:** kiosk mode needs a managed device (Google Admin console).

## 5. Switches

**Settings → Switch scanning.** Most switch interfaces send keys: set yours to send **Space** (switch 1) and **Enter** (switch 2). Game controllers work too (button A is switch 1, B is switch 2). Start with **two switches** (one to move, one to choose) or **by itself** with one switch, a slow speed, and **dim the rest**. With **tap anywhere** on, hold the screen for 3 seconds to get back to edit mode.

## 6. Back up

**Settings → Boards & backup → Back up everything** saves every board, picture and setting in one file. Keep a copy somewhere other than the device. Edit mode reminds you when the boards have changed since the last backup. **Print** (in edit mode) makes paper boards for when the device isn't available.
