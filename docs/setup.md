# Setting up a device

For families, teachers and speech-language pathologists (SLPs) setting up Any AAC for someone. Any AAC is at **[any-aac.com](https://any-aac.com/)**. This is its first release, and its vocabulary hasn't yet been reviewed by SLPs; see the [README](../README.md).

## 1. Install it

Installing keeps the app full screen, lets it work offline, and stops iOS from clearing its data after a week without use.

- **iPhone or iPad:** open the app in Safari, tap Share, then **Add to Home Screen**. Open it from the Home Screen from then on.
- **Android:** open it in Chrome, open the ⋮ menu, then **Install app** (or **Add to Home screen**).
- **Computer:** in Chrome or Edge, use the install button at the right of the address bar.

Edit mode reminds you if the app isn't installed. Updates download in the background and install when the app is put away (another app opened, or the screen locked) with nothing in the message, so they never interrupt someone mid-sentence; the app reopens updated, on Home. When one is waiting, edit mode and **Settings → About** say so and offer **Update now**.

## 2. Choose one main device

Each word has one place on the board, and people learn where words are by moving to them, much as speakers learn to say words. That only works if the places don't change. On phone-sized screens Any AAC shows a smaller board with fewer words in different places, which is a second set of places to learn.

- For someone **starting out**, use a tablet or larger screen with big buttons as the main device. Vocabulary designers recommend this ([PRC-Saltillo](https://prc-saltillo.com/blog/LAMPWFL-iPhone)).
- If they use a **phone and a tablet**, consider turning off **Settings → Display → Smaller layouts on phones**, so both show the same board. The buttons will be small on the phone.

## 3. Choose the starter boards

Devices set to Spanish start with the **Spanish** starter boards, chosen in Spanish for Spanish speakers; others start with the **English** boards, which come with Spanish translations for bilingual communicators. To switch, use **Settings → Boards & backup → Start over with…** (this replaces the boards, so back up first).

## 4. Choose a voice

**Settings → Speech & voice.** Any AAC speaks with an **app voice**: it sounds the same on every device, works offline, and keeps speaking when an iPhone or iPad is in silent mode (iOS mutes the device's own voice then). The starter words speak in it from the first tap. The full voice for the language in use (**Linda** for English) downloads by itself the first time the app opens, about 37 MB once (23 MB for Spanish), so open it on Wi-Fi if you can; until it's ready, words you add speak with the device voice. To use less data, turn off **Download app voices automatically** and download a voice when you choose. The device voice is still there if you prefer it. Any AAC only offers voices whose licences are clearly open; for Spanish that's one small, lower-quality voice for now ([decision 0002](research/decisions/0002-only-clearly-licensed-voices.md)).

Firefox on Android can't speak with device voices; use Chrome, or download an app voice.

## 5. Lock the device

Any AAC's own lock keeps editing behind a press-and-hold on **Edit**. To keep someone in the app, use the device's lock as well:

- **iPhone or iPad: Guided Access.** Settings → Accessibility → **Guided Access** → turn it on and set a passcode. Open Any AAC, triple-click the side button (or the Home button), and tap **Start**. Triple-click again and enter the passcode to end it.
- **Android: App pinning.** Settings → Security (on some phones, Security & privacy → More security settings) → **App pinning** → turn it on. Open Any AAC, open the recent-apps view, tap the app's icon and choose **Pin**. How to unpin varies by phone; it's usually holding Back and Overview, or swiping up and holding.
- **Windows: Kiosk.** Settings → Accounts → Other users → **Set up a kiosk**, choose Microsoft Edge, and give it the app's address.
- **Chromebooks:** kiosk mode needs a managed device (Google Admin console).

## 6. Switches

**Settings → Switch scanning.** Most switch interfaces send keys: set yours to send **Space** (switch 1) and **Enter** (switch 2). Game controllers work too (button A is switch 1, B is switch 2). Start with **two switches** (one to move, one to choose) or **by itself** with one switch, a slow speed, and **dim the rest**. With **tap anywhere** on, hold the screen for 3 seconds to get back to edit mode.

## 7. Modeling

People learn to use AAC by seeing others use it. **Model** (in the edit toolbar: hold Edit, then tap Model) lets partners tap words on the person's own board as they talk: the words are said but don't go into the person's message. **Find a word** shows where any word is, one step at a time.

## 8. Back up

**Settings → Boards & backup → Back up everything** saves every board, picture and setting in one file. Keep a copy somewhere other than the device. Edit mode reminds you when the boards have changed since the last backup. **Print** (in edit mode) makes paper boards for when the device isn't available.
