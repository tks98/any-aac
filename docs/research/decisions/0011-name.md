# 0011: Rename Open AAC to Any AAC

Status: accepted. 2026-10-11.

## Context

The app was developed as "Open AAC", and the plan said to check for a clash with openaac.org before going public ([plan.md §9](../../plan.md#9-risks)). OpenAAC is a US non-profit that promotes open AAC. Its GitHub organisation is `open-aac`, it maintains the Open Board Format that this app reads and writes, and it has its own open-source web AAC app (Sweet Suite). People would take an app called Open AAC for theirs.

## Options

- **Ask OpenAAC to share the name.** Possible, but the confusion would remain whatever they said.
- **Another name.** Names already used by AAC apps were ruled out: LibreAAC (a free, offline, OBF-based Android app), FreeAAC (and FreeSpeech AAC), Simple AAC, Voz AAC (close to VOX AAC and Voz Amiga), Now AAC (GoTalk NOW) and All AAC (close to All in One AAC). Others were clear but didn't fit as well: CommonAAC, WrenAAC, Freely AAC, Every AAC and more.

## Decision

**Any AAC**: any device, any browser, anyone, at no cost. It keeps the plain "something AAC" shape of the first name. On 2026-10-11 there was no AAC app or project by this name, anyaac.org and anyaac.com were unregistered, and there was no GitHub repository or organisation called `any-aac`. We haven't run a trademark search.

## Consequences

- The repository is `tks98/any-aac`, the packages are `@any-aac/core` and `@any-aac/web`, and the hosted address is `https://tks98.github.io/any-aac/` ([0010](0010-hosting.md)).
- Our OBF fields are `ext_anyaac_*`. Boards and files saved with the old `ext_openaac_*` fields are upgraded when they're read (`renameOldFields` in `packages/core/src/ext.ts`), backups made under the old name restore their settings, and old settings carry over.
- Storage, cache and database names keep the first name (`open-aac…`), so nothing saved before the rename is lost, including voices downloaded for offline use.
- "Open AAC voices" are now **app voices** in the interface. "Any AAC voice" would read as "any voice".
