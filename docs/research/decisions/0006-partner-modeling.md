# 0006: Tools for partner modeling

Status: proposed. 2026-10-11.

## Context

Aided language modeling is the best-evidenced AAC teaching practice ([findings/teaching.md](../findings/teaching.md)). Partners need to find words quickly, and what they model shouldn't be taken as the person's own words. No open-source AAC app has tools for this ([foundations.md §3](../foundations.md#3-what-already-exists)).

## Proposed decision

**Find word:** search any word and see the path to it highlighted, one step at a time. **Modeling mode:** while it's on, taps highlight and can be spoken, but don't build the person's message.
